One-click WCAG 2.1 AA compliance for your WordPress site.

== Description ==
Inculva adds a floating accessibility widget to your WordPress site, giving visitors tools to adjust vision, reading, motor, and sensory settings.

Features include high contrast, dark mode, text resizing, dyslexia font, screen reader, keyboard navigation, reading guide, and 20+ more.

== Installation ==
1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings > Inculva Widget
4. Enter your Site ID from https://app.inculva.com
