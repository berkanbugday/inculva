## Widget API — `apps/api` (port 3001)

Base URL in production: `https://api.inculva.com`

All routes allow CORS from any origin (required for the widget embedded on external sites). Rate limit: **100 requests per minute per IP**.

---

### GET /health

Health check endpoint.

**Auth:** None

**Response 200:**
```json
{
  "status": "ok",
  "timestamp": "2026-03-04T10:00:00.000Z"
}
```

---

### GET /widget/config/:siteId

Returns widget configuration and i18n labels for the given site. Called by the embedded widget on page load.

**Auth:** None (public)

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `siteId` | string | The site's database ID |

**Request headers:**
| Header | Description |
|---|---|
| `Origin` | Used to extract the requesting domain for allowlist enforcement |
| `Referer` | Fallback if Origin is absent |

**Response 200:**
```json
{
  "success": true,
  "data": {
    "position": "bottom-right",
    "theme": "auto",
    "primaryColor": "#0066cc",
    "language": "en",
    "labels": {
      "title": "Accessibility Options",
      "textResizing": "Text Resizing",
      "highContrast": "High Contrast",
      "..."  : "..."
    },
    "features": {
      "textResizing": true,
      "highContrast": true,
      "dyslexiaFont": true,
      "cursorEnhancement": true,
      "keyboardNavigation": true,
      "readingGuide": true,
      "screenReader": true,
      "pauseAnimations": true,
      "textSpacing": true,
      "highlightLinks": true,
      "colorBlindMode": true,
      "largeClickTargets": true,
      "focusHighlight": true,
      "grayscale": true,
      "skipNavigation": true,
      "muteMedia": true
    },
    "accessibilityStatementUrl": "https://example.com/accessibility",
    "whiteLabelText": null
  }
}
```

> **Note:** `whiteLabelText` is only included in the response for Business plan sites. `accessibilityStatementUrl` is only included if set.

**Response 404:**
```json
{ "success": false, "error": "Site not found" }
```

**Response 403:**
```json
{ "success": false, "error": "Domain not authorized" }
```
Returned when `allowedDomains` is configured and the requesting domain is not in the list.

**Side effects:**
- Increments the `WidgetLoad` daily counter for the requesting domain (upsert, async, fire-and-forget).

### POST /widget/events

Records an accessibility event from a visitor. Called by the widget via `navigator.sendBeacon` (non-blocking) or as a regular POST.

**Auth:** None (public)

**Request body:**
```json
{
  "siteId": "cm...",
  "sessionId": "uuid-v4",
  "event": "feature_enabled",
  "feature": "highContrast",
  "timestamp": "2026-03-04T10:00:00.000Z"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `siteId` | string | Yes | The site's database ID |
| `sessionId` | string | Yes | Visitor's session UUID (generated by widget, persisted in sessionStorage) |
| `event` | string | Yes | One of: `opened`, `closed`, `feature_enabled`, `feature_disabled` |
| `feature` | string | No | Feature key (only for `feature_enabled`/`feature_disabled` events) |
| `timestamp` | string | No | ISO 8601 timestamp; defaults to server `now()` if absent or invalid |

**Response 204:** No content (success)

**Response 400:**
```json
{ "success": false, "error": "Missing required fields" }
```

**Response 404:**
```json
{ "success": false, "error": "Unknown site" }
```

**Response 429:**
```json
{ "success": false, "error": "Monthly event quota exceeded" }
```
Returned when the site owner's plan monthly limit is reached.

**Side effects:**
- Creates a `WidgetEvent` record.
- At 80% quota: sends usage warning email + in-app notification (once per calendar month).
- At 100% quota: sends limit reached email + in-app notification (once per calendar month), then returns 429.

---

### GET /widget/events/:siteId

Returns up to 1000 widget events for a site. Used by the dashboard analytics page.

**Auth:** `x-api-key` header (SHA-256 hashed API key)

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `siteId` | string | The site's database ID |

**Query parameters:**
| Parameter | Type | Required | Description |
|---|---|---|---|
| `from` | string | No | ISO 8601 start date filter |
| `to` | string | No | ISO 8601 end date filter |

**Request headers:**
```
x-api-key: ink_abc123...
```

**Response 200:**
```json
{
  "success": true,
  "data": [
    {
      "id": "cm...",
      "siteId": "cm...",
      "sessionId": "uuid-v4",
      "event": "feature_enabled",
      "feature": "highContrast",
      "createdAt": "2026-03-04T10:00:00.000Z"
    }
  ]
}
```

**Response 401:**
```json
{ "success": false, "error": "Unauthorized" }
```

## Dashboard API — `apps/web` (port 3000)

Base URL in production: `https://app.inculva.com`

All routes except `/api/auth/*` and `/api/webhooks/*` require an authenticated session cookie. The session cookie is set by Better Auth as an HTTP-only cookie named `better-auth.session_token`.

---

### Auth Routes

#### ALL /api/auth/[...all]

Catch-all route handled by Better Auth. Provides:
- `POST /api/auth/sign-in/email` — email + password sign in
- `POST /api/auth/sign-up/email` — registration
- `POST /api/auth/sign-out` — sign out
- `POST /api/auth/verify-email` — verify email token
- `POST /api/auth/forget-password` — request password reset email
- `POST /api/auth/reset-password` — set new password

Refer to [Better Auth documentation](https://www.better-auth.com/docs) for the full protocol.

#### GET /api/auth/welcome

Triggered after registration to send the welcome email.

**Auth:** Session cookie

**Response 200:** `{ "ok": true }`

---

### Account Routes

#### DELETE /api/account/delete

Permanently deletes the authenticated user's account and all associated data (cascade: sites, events, teams, subscriptions).

**Auth:** Session cookie

**Response 200:** `{ "ok": true }`

---

### Admin Routes

> All admin routes require `User.role === "admin"`.

#### PUT /api/admin/users/[id]/plan

Force-sets a user's plan (admin override, bypasses billing).

**Auth:** Session cookie + admin role

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `id` | string | Target user's ID |

**Request body:**
```json
{ "plan": "pro" }
```

Allowed values: `"free"`, `"pro"`, `"business"`

**Response 200:** `{ "ok": true }`

---

### Billing Routes

#### POST /api/checkout

Creates a LemonSqueezy hosted checkout URL and redirects the user.

**Auth:** Session cookie

**Request body:**
```json
{ "variantId": 123456 }
```

**Response:** Redirect to LemonSqueezy checkout URL

#### POST /api/billing/cancel-subscription

Cancels the authenticated user's active LemonSqueezy subscription.

**Auth:** Session cookie

**Response 200:** `{ "ok": true }`

**Response 400:** `{ "error": "No active subscription found" }`

---

### API Key Routes

#### GET /api/keys

Returns all API keys for the authenticated user.

**Auth:** Session cookie

**Response 200:**
```json
{
  "keys": [
    {
      "id": "cm...",
      "name": "My Key",
      "keyPrefix": "ink_a1b2",
      "lastUsedAt": null,
      "expiresAt": null,
      "createdAt": "2026-03-04T10:00:00.000Z",
      "revokedAt": null
    }
  ]
}
```

#### POST /api/keys

Creates a new API key for the authenticated user.

**Auth:** Session cookie

**Request body:**
```json
{ "name": "My Key" }
```

**Response 201:**
```json
{
  "key": {
    "id": "cm...",
    "name": "My Key",
    "keyPrefix": "ink_a1b2",
    "rawKey": "ink_a1b2c3d4...",
    "createdAt": "2026-03-04T10:00:00.000Z"
  }
}
```

> **Security note:** `rawKey` is returned only once. It is not stored. Store it immediately.

#### DELETE /api/keys/[id]

Revokes an API key (sets `revokedAt` timestamp).

**Auth:** Session cookie

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `id` | string | API key ID |

**Response 200:** `{ "ok": true }`

### Notification Routes

#### GET /api/notifications

Returns the 20 most recent notifications for the authenticated user.

**Auth:** Session cookie

**Response 200:**
```json
{
  "notifications": [
    {
      "id": "cm...",
      "type": "plan_upgraded",
      "title": "You're now on Pro!",
      "body": "Your plan has been upgraded to Pro.",
      "href": "/dashboard/settings/billing",
      "readAt": null,
```

Marks all unread notifications as read.

### Sites Routes

#### PUT /api/sites/[id]/config

Updates the widget configuration for a site.

**Auth:** Session cookie (must be site owner or team member)

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `id` | string | Site ID |

**Request body:**
```json
{
  "position": "bottom-left",
  "theme": "dark",
  "primaryColor": "#ff6600",
  "language": "de",
  "textResizing": true,
  "highContrast": false,
  "dyslexiaFont": true,
  "cursorEnhancement": true,
  "keyboardNavigation": true,
  "readingGuide": true,
  "screenReader": true,
  "pauseAnimations": true,
  "textSpacing": true,
  "highlightLinks": true,
  "colorBlindMode": true,
  "largeClickTargets": true,
  "focusHighlight": true,
  "grayscale": true,
  "skipNavigation": true,
  "muteMedia": true,
  "accessibilityStatementUrl": "https://example.com/accessibility",
```

#### GET /api/sites/[id]/check-install

Checks whether the widget script tag is present on the site's domain by fetching the site's homepage.

**Auth:** Session cookie

**Response 200:**
```json
{ "installed": true }
```
or
```json
{ "installed": false }
```

---

### Team Routes

#### POST /api/teams/[id]/invites

Sends a team invitation email and creates a pending invite record.

**Auth:** Session cookie + team admin role

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `id` | string | Team ID |

**Request body:**
```json
{
  "email": "newmember@example.com",
  "role": "member"
}
```

`role`: `"admin"` or `"member"`

**Response 201:** `{ "ok": true }`

#### DELETE /api/teams/[id]/invites/[inviteId]

Cancels a pending invite.

**Auth:** Session cookie + team admin role

**Response 200:** `{ "ok": true }`

#### DELETE /api/teams/[id]/members/[memberId]

Removes a member from the team.

**Auth:** Session cookie + team admin role

**Response 200:** `{ "ok": true }`

---

### Webhook Routes

#### POST /api/webhooks/lemonsqueezy

Receives LemonSqueezy billing events. Verifies HMAC-SHA256 signature before processing.

**Auth:** `X-Signature` header (HMAC-SHA256, verified against `LEMONSQUEEZY_WEBHOOK_SECRET`)

**Handled events:**
| Event | Action |
|---|---|
| `subscription_created` | Create `Subscription` record, update `User.plan`, send email + notification |
| `subscription_updated` | Update `Subscription` record, sync plan |
| `subscription_cancelled` | Mark subscription as cancelled |
| `subscription_expired` | Revert `User.plan` to `free`, update subscription status |

**Response 200:** `{ "ok": true }`

**Response 401:** Signature verification failed

## Common Response Format

Success responses follow this pattern:

```typescript
interface ApiResponse<T> {
  success: true;
  data: T;
}
```

Error responses:

```typescript
interface ApiError {
  success: false;
  error: string;
}
```

---

## Error Codes

| HTTP Status | Meaning |
|---|---|
| 200 | Success |
| 201 | Created |
| 204 | No content (success, no body) |
| 400 | Bad request (missing or invalid fields) |
| 401 | Unauthorized (missing or invalid auth) |
| 403 | Forbidden (authenticated but insufficient permissions) |
| 404 | Resource not found |
| 429 | Rate limited or quota exceeded |
| 500 | Internal server error |
