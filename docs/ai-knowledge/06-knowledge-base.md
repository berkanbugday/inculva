# inculva — Knowledge Base

## Overview

The inculva Knowledge Base is a comprehensive, bilingual (English and Turkish) resource covering all WCAG 2.0, 2.1, and 2.2 success criteria, plus guides on SEO, GEO (Generative Engine Optimization), AEO (Answer Engine Optimization), and accessibility best practices.

**URL:** https://inculva.com/kb/

## Content

### WCAG Rule Articles (87 total)

Every WCAG success criterion has a dedicated article that includes:

1. **Quick Answer** — 2-3 sentence plain-language summary
2. **What This Rule Means** — Detailed explanation of the criterion
3. **Why It Matters** — Real user impact, disability context
4. **Related axe-core Rules** — Each automated rule explained with examples
5. **How to Test** — Manual testing steps + automated scanning guidance
6. **How to Fix** — Code examples (before/after)
7. **Common Mistakes** — What developers get wrong
8. **FAQ** — Structured Q&A
9. **Resources** — Curated external links to W3C, Deque, WebAIM, MDN, and more

### WCAG Rules by Principle

**Perceivable (Guideline 1)**
- 1.1 Text Alternatives — Provide alt text for non-text content
- 1.2 Time-based Media — Provide captions and audio descriptions
- 1.3 Adaptable — Content can be presented in different ways
- 1.4 Distinguishable — Make it easier to see and hear content

**Operable (Guideline 2)**
- 2.1 Keyboard Accessible — All functionality available from keyboard
- 2.2 Enough Time — Give users enough time to read and use content
- 2.3 Seizures and Physical Reactions — Don't design content that causes seizures
- 2.4 Navigable — Help users navigate and find content
- 2.5 Input Modalities — Make it easier to operate through various inputs

**Understandable (Guideline 3)**
- 3.1 Readable — Make text readable and understandable
- 3.2 Predictable — Make pages appear and operate in predictable ways
- 3.3 Input Assistance — Help users avoid and correct mistakes

**Robust (Guideline 4)**
- 4.1 Compatible — Maximize compatibility with assistive technologies

## Integration with Scanner

When the inculva scanner detects a WCAG violation, it links directly to the relevant KB article. This means users can go from "you have a color contrast issue" straight to a detailed explanation of WCAG 1.4.3 with code examples showing how to fix it.
