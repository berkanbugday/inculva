# inculva — Frequently Asked Questions

## General

### What is inculva?
inculva is a web accessibility platform that helps websites achieve WCAG compliance automatically. It provides an embeddable accessibility widget with 24 features, automated WCAG scanning, analytics, and a comprehensive knowledge base.

### What is WCAG compliance?
WCAG (Web Content Accessibility Guidelines) is an international standard for making web content accessible to people with disabilities. Compliance ensures your website can be used by everyone, including people who use screen readers, have low vision, color blindness, motor impairments, or cognitive disabilities.

### Who is inculva for?
inculva is for any website owner, developer, or organization that wants to make their website accessible. This includes small businesses, e-commerce sites, government agencies, educational institutions, and enterprise organizations.

### Do I need technical knowledge to use inculva?
No. inculva is designed to be used by anyone. Simply paste one line of code into your website, and the platform handles the rest. No coding skills are needed for the widget installation.

## Widget

### Does inculva slow down my website?
No. The inculva widget is loaded asynchronously and optimized for performance. It's approximately 30kb minified and does not block page rendering.

### Does the widget work on mobile devices?
Yes. The widget is fully responsive and works on all devices including phones, tablets, and desktops.

### Can I customize the widget's appearance?
Yes. You can customize the button position (left or right), button size, button icon, panel language, header and footer colors, and choose which features and profiles are enabled.

### How many languages does the widget support?
The widget panel supports 41 languages, including RTL (right-to-left) languages like Arabic, Hebrew, Farsi, and Urdu.

### Do visitor preferences persist?
Yes. The widget saves user preferences in the browser's localStorage, so visitors keep their accessibility settings across page loads and return visits.

### Can I remove the "Powered by inculva" branding?
Yes, with the Large plan. White-label branding allows you to remove or replace the inculva attribution.

### What accessibility profiles are available?
Six pre-configured profiles: Blind, Low Vision, Dyslexia, Color Blind, Motor Impaired, and ADHD. Each activates a combination of features tailored for that need. Site owners can enable or disable individual profiles.

## Scanning

### What does the scanner check?
The scanner checks for 60+ accessibility rules based on WCAG 2.1 and 2.2, including image alt text, color contrast, ARIA attributes, keyboard accessibility, form labels, heading structure, link text, focus management, and more.

### How does scanning work?
The scanner crawls your website using a headless browser, visiting each page and running axe-core (the industry-standard accessibility testing engine) against the rendered DOM.

### What is a compliance score?
Each scan produces a score from 0 to 100 based on the ratio of passed rules to total rules checked. Track this score over time to monitor your accessibility improvement.

### What is an "incomplete" result?
Incomplete results are rules that axe-core could not fully evaluate automatically. These may need manual review to determine if they are actual violations.

## Compliance & Legal

### Which accessibility standards does inculva support?
inculva supports WCAG 2.1 Level AA and AAA, ADA (Americans with Disabilities Act), Section 508, EN 301 549, and the European Accessibility Act (EAA).

### Does using inculva guarantee full WCAG compliance?
The widget provides significant accessibility improvements and the scanner identifies most automatable issues. However, full WCAG compliance also requires manual testing and proper accessible development practices. inculva is a powerful tool in your compliance strategy, but we recommend combining it with manual audits for complete coverage.

### Can inculva generate an accessibility statement?
Yes. The dashboard includes an accessibility statement generator that creates EAA Article 13 compliant statements. You can link the statement URL in the widget configuration so visitors can access it.
